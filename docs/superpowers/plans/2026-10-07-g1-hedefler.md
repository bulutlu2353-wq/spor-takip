# G1 — Hedef Çekirdeği Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tek `goal` alanını iki eksenli hedefle (kilo yönü + hız, çoklu odak) değiştirmek; kaloriyi haftalık hıza göre, proteini hedefe göre hesaplamak; onboarding ve koçu yeni modele geçirmek.

**Architecture:** `profiles` tablosuna `weight_direction`, `pace`, `focuses text[]` eklenir, `goal` düşer (migration mevcut kayıtları taşır). Dart'ta `Goal` enum'u yerine `WeightDirection`, `Pace`, `GoalFocus` gelir; tüm hedef hesabı `TdeeCalculator`'da kalır. Onboarding'e üç adım (yön → hız → odak) eklenir; koç `set_goal` aracı hedefin tamamını taşır.

**Tech Stack:** Flutter (Riverpod, easy_localization), Supabase Postgres (plpgsql), Deno Edge Function.

**Spec:** `docs/superpowers/specs/2026-10-07-g1-hedefler-design.md`

## Global Constraints

- Dal: `g1-hedefler` (zaten açık, spec commit'li).
- Tüm `flutter` komutları `--no-pub` ile (otomatik `pub get` bu makinede takılıyor).
- Düşük bellekli makine: görev içinde sadece ilgili test dosyaları çalıştırılır. Tam paketi kullanıcı kendi terminalinde çalıştırır (`flutter test --no-pub -j 1`, Task 5). `flutter analyze --no-pub` birkaç dakika sürebilir; gerekirse arka planda çalıştır, "No issues found!" vermeli.
- `dart format` çalıştırılmaz (projede satır genişliği ayarı yok); mevcut biçime elle uyulur.
- Deno testleri: `deno test supabase/functions/coach-chat/`.
- Migration ve SQL check'leri kullanıcı Supabase SQL Editor'da çalıştırır; Edge function deploy'u kullanıcı yapar.
- Hız oranları (haftalık, vücut ağırlığı oranı): kilo ver yavaş/dengeli/hızlı = 0.005 / 0.0075 / 0.01; kilo al = 0.0025 / 0.0035 / 0.005. 1 kg = 7700 kcal.
- Kalori tabanı: erkek 1500, kadın ve belirtilmemiş 1200; taban hedefi TDEE'nin üstüne çıkarmaz (`max(tdee + delta, min(tdee, taban))`).
- Protein g/kg: kilo veriyorsa 2.2; değilse kas veya güç odağı varsa 2.0; değilse 1.6.
- Commit mesajları şu satırla biter: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## Spec'ten bilinçli sapmalar (kullanıcıya bildirilecek)

1. Odak enum'u `Focus` değil **`GoalFocus`**: `Focus`, `package:flutter/material.dart`'taki widget ile çakışır.
2. Taban formülü `max(tdee + delta, min(tdee, taban))`: taban açığı sınırlar ama TDEE'si tabandan düşük birinin hedefini TDEE'nin üstüne çıkarmaz (spec'teki `max(tdee ± delta, taban)` korumada bile hedefi yükseltirdi). Migration aynı formülü kullanır.
3. Onboarding'de "koru" seçilince `pace` cevaplardan silinmez; `buildProfileFromAnswers` korumada `pace`'i null yazar (`sportType` deseni). Geri dönüp "ver" seçen kullanıcının önceki hız seçimi korunur.
4. G1 öncesi uygulanmış eski `set_goal` olayının geri alınması **`modified`** döner (spec "stale" diyordu): `undo_chat_action` mevcut görüntüyü `after` ile karşılaştırdığından ek kod gerekmeden engellenir; kartta "değişti" görünür ve geri al pasifleşir. Bekleyen eski olay uygulanmaya çalışılırsa zaten `stale` döner.
5. Eski olay kartındaki hedef değer etiketleri `onboarding.goal_*` yerine `coach.legacy_goal.*` altına taşınır (onboarding anahtarları silindiği için).

```sql
-- G1: tek `goal` yerine kilo yönü + hız + odaklar
-- (spec docs/superpowers/specs/2026-10-07-g1-hedefler-design.md §3).

alter table public.profiles
  add column weight_direction text,
  add column pace text,
  add column focuses text[] not null default '{}';

-- Mevcut kayıtları taşı. Saklanan kalori hedefi bugün TDEE'ye eşit; kilo verenlere
-- dengeli açık uygulanır (kilo × 0.0075 × 7700 / 7 = kilo × 8.25). Taban açığı
-- sınırlar ama hedefi TDEE'nin üstüne çıkarmaz.
update public.profiles set
  weight_direction = case goal when 'lose_weight' then 'lose' else 'maintain' end,
  pace = case goal when 'lose_weight' then 'balanced' end,
  focuses = case goal
    when 'gain_muscle' then array['muscle']
    when 'maintain' then array['general']
    else '{}'::text[] end,
  daily_calorie_target = case goal
    when 'lose_weight' then greatest(
      daily_calorie_target - weight_kg * 8.25,
      least(daily_calorie_target, case gender when 'male' then 1500 else 1200 end))
    else daily_calorie_target end,
  daily_protein_target_g = weight_kg * case goal
    when 'lose_weight' then 2.2
    when 'gain_muscle' then 2.0
    else 1.6 end,
  updated_at = now();

-- CHECK içinde alt sorgu kullanılamadığı için tekrarsızlık bir fonksiyonla.
create or replace function public.text_array_is_distinct(a text[])
returns boolean
language sql
immutable
as $$
  select cardinality(a) = (select count(distinct x) from unnest(a) x);
$$;

alter table public.profiles
  alter column weight_direction set not null;

alter table public.profiles
  add constraint profiles_weight_direction_check
    check (weight_direction in ('lose', 'maintain', 'gain')),
  add constraint profiles_pace_check
    check (pace in ('slow', 'balanced', 'fast')),
  add constraint profiles_pace_direction_check
    check ((weight_direction = 'maintain') = (pace is null)),
  add constraint profiles_focuses_check
    check (focuses <@ array['muscle', 'strength', 'endurance', 'general']
           and public.text_array_is_distinct(focuses));

alter table public.profiles drop column goal;
```

Dosyanın tamamını şununla değiştir:

```dart
import 'dart:math' as math;

import 'profile.dart';

class TdeeResult {
  const TdeeResult({required this.calorieTarget, required this.proteinTargetG});

  final double calorieTarget;
  final double proteinTargetG;
}

/// Haftalık kilo değişimi, vücut ağırlığının oranı olarak (spec §4.2).
const Map<WeightDirection, Map<Pace, double>> weeklyRates = {
  WeightDirection.lose: {Pace.slow: 0.005, Pace.balanced: 0.0075, Pace.fast: 0.01},
  WeightDirection.gain: {Pace.slow: 0.0025, Pace.balanced: 0.0035, Pace.fast: 0.005},
};

const double _kcalPerKg = 7700;

/// Haftalık tahmini kilo değişimi (kg, işaretsiz); korumada ya da hız yoksa 0.
double weeklyChangeKg(double weightKg, WeightDirection direction, Pace? pace) {
  final rate = pace == null ? null : weeklyRates[direction]?[pace];
  return rate == null ? 0 : weightKg * rate;
}

class TdeeCalculator {
  const TdeeCalculator();

  static const Map<ActivityLevel, double> _activityMultipliers = {
    ActivityLevel.sedentary: 1.2,
    ActivityLevel.light: 1.375,
    ActivityLevel.moderate: 1.55,
    ActivityLevel.active: 1.725,
    ActivityLevel.veryActive: 1.9,
  };

  double _bmr({
    required double weightKg,
    required double heightCm,
    required int age,
    required Gender gender,
  }) {
    final base = 10 * weightKg + 6.25 * heightCm - 5 * age;
    switch (gender) {
      case Gender.male:
        return base + 5;
      case Gender.female:
        return base - 161;
      case Gender.unspecified:
        return ((base + 5) + (base - 161)) / 2;
    }
  }

  /// Kilo verirken kası korumak için en yüksek; kas/güç odağında orta; diğerlerinde 1.6.
  double _proteinPerKg(WeightDirection direction, Set<GoalFocus> focuses) {
    if (direction == WeightDirection.lose) return 2.2;
    if (focuses.contains(GoalFocus.muscle) || focuses.contains(GoalFocus.strength)) return 2.0;
    return 1.6;
  }

  TdeeResult calculate({
    required double weightKg,
    required double heightCm,
    required int birthYear,
    required int currentYear,
    required Gender gender,
    required ActivityLevel activityLevel,
    required WeightDirection weightDirection,
    required Pace? pace,
    required Set<GoalFocus> focuses,
  }) {
    final age = currentYear - birthYear;
    final bmr = _bmr(
      weightKg: weightKg,
      heightCm: heightCm,
      age: age,
      gender: gender,
    );
    final tdee = bmr * _activityMultipliers[activityLevel]!;
    final dailyDelta = weeklyChangeKg(weightKg, weightDirection, pace) * _kcalPerKg / 7;
    final signedDelta = weightDirection == WeightDirection.lose ? -dailyDelta : dailyDelta;
    final floor = gender == Gender.male ? 1500.0 : 1200.0;
    // Taban açığı sınırlar ama hedefi TDEE'nin üstüne çıkarmaz.
    final calorieTarget = math.max(tdee + signedDelta, math.min(tdee, floor));
    final proteinTargetG = weightKg * _proteinPerKg(weightDirection, focuses);
    return TdeeResult(calorieTarget: calorieTarget, proteinTargetG: proteinTargetG);
  }
}
```

```ts
function prepareGoal(args: Args, ctx: ToolContext): PreparedTool {
  const direction = oneOf(args, 'weight_direction', DIRECTIONS);
  let pace: (typeof PACES)[number] | null = null;
  if (direction === 'maintain') {
    if (present(args, 'pace')) throw new ToolArgError('pace must be omitted when maintaining weight');
  } else {
    pace = oneOf(args, 'pace', PACES);
  }
  if (!Array.isArray(args.focuses) || args.focuses.length === 0) {
    throw new ToolArgError('focuses must be a non-empty array');
  }
  for (const value of args.focuses) {
    if (typeof value !== 'string' || !(FOCUSES as readonly string[]).includes(value)) {
      throw new ToolArgError(`focuses must be among: ${FOCUSES.join(', ')}`);
    }
  }
  // Tekrarlar düşer, sıra sabitlenir (DB ve kart karşılaştırmaları için).
  const focuses = FOCUSES.filter((f) => (args.focuses as string[]).includes(f));
  const p = ctx.data.profile;
  if (p && p.weight_direction === direction && p.pace === pace && p.focuses.join() === focuses.join()) {
    throw new ToolArgError('goal is already the current goal');
  }
  const labels = LABELS[ctx.locale];
  const head = labels.directions[direction] + (pace ? ` (${labels.paces[pace]})` : '');
  return {
    ok: true,
    tool: 'set_goal',
    summary: `${labels.goal}: ${head} · ${focuses.map((f) => labels.focuses[f]).join(', ')}`,
    payload: { weight_direction: direction, pace, focuses },
  };
}
```

(DB `focuses`'u enum sırasıyla yazar — Dart `focusesToDb` ve bu fonksiyon aynı sırayı kullanır — bu yüzden `join()` karşılaştırması yeterli.)
